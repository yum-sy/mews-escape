# Pokémon — Mew's Escape · Phase 4

[게임 실행](https://yum-sy.github.io/mews-escape/)

가장 깊은 연구소에 갇혔던 뮤가 무너진 격리 장치를 빠져나와 지상으로 올라가는 웹 액션 로그라이크입니다. Phaser 3 + TypeScript + Vite, GitHub Pages 배포.

## 이번 버전

- 약 49초의 6장면 오프닝: 평화로운 숲 → 인간의 포획 → 반복 실험 → 뮤츠의 각성 → 연구소 붕괴 → 탈출 시작. 장면 넘기기/건너뛰기, 동작 줄이기 설정 대응.
- 메인 메뉴: 게임 시작 / 게임 설명(조작 포함) / 게임 설치.
- 전체 구조는 **B6 → B5 → B4 → B3 → B2 → B1 → 지상**. B6~B2의 55개 방 뒤에 B1 뮤츠 전용 아레나가 연결됩니다. 총 6개 층·56개 방이며 최종 3연전 후 엔딩에 도달합니다.
- 층별 전투방 5→6→7→8→9개, 매 층 보상방 2개, 시작방 1개, 팬텀 승강기 제어실 1개. 전투방을 모두 클리어해야 그 층의 팬텀에게 도전할 수 있습니다.
- 보스 처치 후 방 중앙으로 이동하면 한 층 위로 올라갑니다. 현재 HP와 기술은 유지되고 새 던전이 생성됩니다.
- 고오스, 주뱃, 또가스, 질퍽이, 델빌, 어둠대신 + 2단계 중간 보스 팬텀.
- 기술/강화 19종, 합성 가능한 숫자 효과 채널 18개. 빌드는 한 판 동안 누적됩니다.
- 독가스, 예고 레이저, 전기 장판, 이동/탄환을 막는 장비, 순간이동 예고, 적의 독 장판, 부유 적의 지형 통과.
- 작은 혈흔, 천 조각, 흩어진 서류와 유리, 파손된 가구, 조사 가능한 연구 기록.
- Web Audio 배경 패턴(탐험/전투/보스)과 효과음. 기본 음소거.
- PWA manifest와 버전별 오프라인 캐시. 설치 지원 브라우저의 실제 설치 프롬프트, iOS/비지원 브라우저의 홈 화면 추가 안내.

## 조작

|입력|기능|
|---|---|
|WASD|이동|
|방향키|8방향 연속 공격. 인접 키 동시 입력으로 대각선|
|E|가까운 연구 기록 조사. 해당 방이 안전할 때만 가능|
|Esc / 정지 버튼|일시정지·재개|
|터치 왼쪽 스틱|이동|
|터치 오른쪽 스틱|360° 조준, 중앙 데드존에서는 발사 중지|
|조사 버튼|터치 환경에서 가까운 기록 읽기|

열린 문 중앙으로 이동하면 다음 방에 들어갑니다. 클리어 상태와 받은 보상은 해당 판에서 유지됩니다. 전투방 클리어/보상방 진입 시 세 기술 중 하나를 선택하고 HP 1을 회복합니다. 모든 기술의 습득 한도에 도달하면 회복 보상으로 대체되어 진행이 막히지 않습니다.

새 판은 성장·체력·적·방·층·시간을 초기화합니다. 새로고침 후에는 같은 브라우저의 마지막 체크포인트에서 이어할 수 있습니다. 앱 설치와 오프라인 실행도 지원합니다.

## 크기와 난이도

`src/species.json`에 PokéAPI 원본 CSV의 키/몸무게와 PNG 불투명 영역을 저장합니다. 키는 decimeter 단위이며, 보이는 높이는 `32 × sqrt(키(m) / 0.4)` 게임 픽셀입니다. 1:1 비율 대신 완만한 제곱근 스케일을 써서 플레이 공간을 유지합니다. PNG의 투명 여백을 프레임에서 제외해 각 그림의 여백 차이가 크기 비교를 왜곡하지 않게 했습니다. 충돌 반경도 표시 높이와 연동됩니다.

|포켓몬|도감 키|표시 높이(약)|
|---|---:|---:|
|뮤|0.4m|32px|
|고오스|1.3m|58px|
|주뱃|0.8m|45px|
|또가스|0.6m|39px|
|질퍽이|0.9m|48px|
|델빌|0.6m|39px|
|어둠대신|0.6m|39px|
|팬텀|1.5m|62px|

층 상승 횟수를 L(0~4)이라 할 때 일반 적 체력은 `1 + 0.5L + 0.16L²`배, 속도는 `1 + 0.07L`배, 적 탄속은 `1 + 0.12L`배입니다. 팬텀 체력에는 `1 + 0.15L`가 추가 적용됩니다. B6 팬텀 HP는 220, B2는 약 1957입니다. 높은 층에서는 시설 기믹과 적 수가 추가되고 시설의 재작동 간격이 줄어듭니다. 실제 클리어 난이도는 지속 조정 대상입니다.

- 레이저: 1초 예고 → 0.9초 작동 → 휴지기. 가로 구간을 피해야 합니다.
- 독가스/적의 독 웅덩이: 접촉 후 2초간 중독 잔류. 처음에는 0.65초 반응 여유가 있습니다.
- 전기: 피해와 0.6초 이동 둔화.
- 고정 장비: 이동 및 양쪽 탄환을 차단. 부유 적은 넘어옵니다.
- 팬텀: 예고 후 반대편으로 순간이동하고 방사 탄막. HP 절반 아래에서는 12방향 탄막과 플레이어 위치의 예고 독 장판.

## 기술 합성

섀도볼, 스피드스타, 트라이어택, 불꽃세례, 얼다바람, 전기쇼크, 분열 강화, 환상빔, 고속이동, 독침, 용의파동, 기가드레인, 기충전, 반사 강화, 오물폭탄, 물대포, 냉동빔, 10만볼트, 화염방사.

각 기술은 `src/moves.ts`의 독립 modifier 데이터로 기본 공격에 가산됩니다. 색은 우선순위가 높은 기술, 동률이면 최근 기술을 사용하며 색 변화가 이전 효과를 지우지 않습니다. 현재 빔/화염 명칭의 기술은 빔 전용 렌더러 대신 기존 투사체에 사거리/관통/연사/상태 효과를 합성하는 데모 구현입니다.

효과 채널: 공격력, 간격, 탄속, 사거리, 크기, 개수, 관통, 유도, 분열, 화상, 둔화, 연쇄, 중독, 넉백, 치명타, 흡혈, 벽 반사, 폭발.

분열은 원탄 첫 적중에서만 발생하며 자탄은 재분열하지 않습니다. 자탄은 원탄 피해 35%, 지속 피해 50%, 사거리 360이며 관통·연쇄·폭발·반사·흡혈을 발생시키지 않습니다. 원탄의 연쇄(30%)와 폭발(25%)은 첫 적중에서만 발생하며, 후속 관통 적중은 위력이 매번 20% 감소합니다. 동일 탄환이 같은 적에게 반복 피해를 주지 않습니다. 화상과 중독은 함께 적용하고, 재적중은 지속 시간을 갱신합니다.

상한: 동시 발사 5, 최소 간격 0.13초, 추가 관통 4, 유도 4.4, 둔화 45%, 연쇄 3, 반경 11, 탄속 960, 사거리 1200, 치명타 24%, 벽 반사 2, 폭발 범위 100. 총 탄환 상한 120을 플레이어 80/적 40으로 나누어, 플레이어 탄막이 적의 발사 자리를 소진하지 않게 합니다.

## 실행·배포

Node.js 22 이상.

```sh
npm install
npm run dev
npm test
npm run build
```

`main` push 시 GitHub Actions가 테스트/빌드 후 Pages로 배포합니다. `npm run build`는 전체 로컬 게임 리소스의 버전별 precache를 생성합니다. 새 서비스 워커는 기존 게임 창이 닫힌 뒤 활성화되어 진행 중인 판을 강제로 재시작하지 않습니다. 설치 화면에서 오프라인 준비 완료를 확인할 수 있습니다.

`?seed=3`처럼 10진수 32비트 시드를 지정하면 같은 던전/선택 경로를 재현합니다. 시드를 빼면 매번 새 판입니다. 층별 시드는 최초 시드에서 파생됩니다.

개발 서버의 `?qa=1`에는 브라우저 검증용 팬텀/복합 효과 버튼이 있습니다. 빌드 시 제거되며 배포판에서는 활성화되지 않습니다.

- `scene.ts`: Phaser 렌더링, 전투 및 UI 연결.

남은 검증: 모바일 실기기 설치·FPS, 정상 플레이로 6개 층 전체의 장시간 밸런스.


## 2026-11-15 이미지·밸런스 수정

- 오프닝의 직접 그린 뮤/뮤츠를 PokéAPI `sprites.other.official-artwork.front_default` 원본 PNG로 교체. API 응답의 주소에서 내려받아 로컬 캐시하며, 출처·파일 해시는 `public/assets/artwork-sources.json`에 기록.
- 포획 탐조등/망, 숲의 안개·풀, 격리 유리·기포, 붕괴 불꽃을 보강. 캐릭터 원화는 변형하거나 다시 그리지 않음.
- 다중탄은 각 탄 피해를 `1 + 0.5 × (탄 수 - 1)`로 나누어, 3발 총 직접 피해 1.5배 / 5발 1.67배. 공격력·연사·지속 피해·회복 강화도 하향.
- 초반 일반 적 HP 3~8 → 5~12, 추적 속도 증가, 적 탄속 180 → 220, 최초 공격 대기 단축. 진입 무적·보상 선택 흐름·클리어 회복은 유지.
- 세부 수치와 한계: docs/BALANCE.md. 27개 테스트 통과; 전체 5개 층의 수동 밸런스 검증은 아직 완료하지 않음.


## Phase 4 — 마지막 문 / 저장

- B6~B2 55개 방 뒤에 B1 전용 아레나가 연결되어 총 56개 방. 뮤츠 3단계: 조준 부채꼴·원형 탄막 → 순간이동·추적탄 → 폭주 탄막·1초 예고 후 0.5초 빔. 빔은 현재 위치를 고정 조준하므로 이동으로 회피 가능.
- 단계별 HP 600 / 750 / 900. 대사 사이에는 전투가 멈추고, 단계 전환 때 체력을 회복시키지 않음. 3단계 격파 후 세 컷 엔딩과 탈출 기록 표시.
- 오프닝: 원본 Pokémon 아트워크 유지, 원경/근접 카메라 컷·전경 가지·연구소 조명·종이 질감 프레임 보강. 모션 코믹 방식이며 프레임별 캐릭터 작화 영상은 아님.
- 자동 저장: 방 진입, 방 클리어, 보상 선택, 뮤츠 단계 전환, 엔딩 진입. 새로고침/브라우저 재실행 시 타이틀의 이어하기 사용.
- 저장은 같은 브라우저의 localStorage에 보관. 던전 seed/방 상태/위치한 방/기술/체력/처치 수/플레이 시간/흡혈 누적/보스 단계를 복원. 전투 중 종료하면 마지막 체크포인트 HP와 적 상태에서 다시 시작하며, 프레임 단위 위치/탄환은 저장하지 않음.
- 엔딩 도중 종료하면 엔딩부터 재개. 엔딩 완료·사망 시 활성 진행 삭제. 새 게임은 기존 진행 덮어쓰기. 기기 간 동기화 없음.
- 저장소 차단/용량 문제는 메시지로 표시하고 플레이는 유지. 손상되거나 지원하지 않는 저장은 읽지 않으며 새 게임 진입 가능. API 키나 계정 없음.
- 테스트 33개 + 브라우저에서 세 단계/엔딩/일반 보상/재접속 확인. 개발 fixture는 빌드에서 제거됨. 정상 빌드 전체 6층 수동 클리어 및 실기기 성능 검증은 별도.
