# Pokémon — Mew's Escape · Phase 3

[게임 실행](https://yum-sy.github.io/mews-escape/)

가장 깊은 연구소에 갇혔던 뮤가 무너진 격리 장치를 빠져나와 지상으로 올라가는 웹 액션 로그라이크입니다. Phaser 3 + TypeScript + Vite, GitHub Pages 배포.

## 이번 버전

- 약 37초의 6장면 오프닝: 평화로운 숲 → 인간의 포획 → 반복 실험 → 뮤츠의 각성 → 연구소 붕괴 → 탈출 시작. 장면 넘기기/건너뛰기, 동작 줄이기 설정 대응.
- 메인 메뉴: 게임 시작 / 게임 설명(조작 포함) / 게임 설치.
- 전체 구조는 **B6 → B5 → B4 → B3 → B2 → B1 → 지상**. 현재는 B6~B2의 5개 층, 총 55개 방을 연속 플레이합니다. B2 완료 후 B1의 뮤츠를 예고하고 데모가 끝납니다.
- 층별 전투방 5→6→7→8→9개, 매 층 보상방 2개, 시작방 1개, 팬텀 승강기 제어실 1개. 전투방을 모두 클리어해야 그 층의 팬텀에게 도전할 수 있습니다.
- 보스 처치 후 방 중앙으로 이동하면 한 층 위로 올라갑니다. 현재 HP와 기술은 유지되고 새 던전이 생성됩니다.
- 고오스, 주뱃, 또가스, 질퍽이, 델빌, 어둠대신 + 2단계 중간 보스 팬텀.
- 기술/강화 19종, 합성 가능한 숫자 효과 채널 18개. 빌드는 한 판 동안 누적됩니다.
- 독가스, 예고 레이저, 전기 장판, 이동/탄환을 막는 장비, 순간이동 예고, 적의 독 장판, 부유 적의 지형 통과.
- 작은 혈흔, 천 조각, 흩어진 서류와 유리, 파손된 가구, 조사 가능한 연구 기록.
- Web Audio 배경 패턴(탐험/전투/보스)과 효과음. 기본 음소거.
- PWA manifest와 버전별 오프라인 캐시. 설치 지원 브라우저의 실제 설치 프롬프트, iOS/비지원 브라우저의 홈 화면 추가 안내.

## 조작

|입력|기능|
|---|---|
|WASD|이동|
|방향키|8방향 연속 공격. 인접 키 동시 입력으로 대각선|
|E|가까운 연구 기록 조사. 해당 방이 안전할 때만 가능|
|Esc / 정지 버튼|일시정지·재개|
|터치 왼쪽 스틱|이동|
|터치 오른쪽 스틱|360° 조준, 중앙 데드존에서는 발사 중지|
|조사 버튼|터치 환경에서 가까운 기록 읽기|

열린 문 중앙으로 이동하면 다음 방에 들어갑니다. 클리어 상태와 받은 보상은 해당 판에서 유지됩니다. 전투방 클리어/보상방 진입 시 세 기술 중 하나를 선택하고 HP 1을 회복합니다. 모든 기술의 습득 한도에 도달하면 회복 보상으로 대체되어 진행이 막히지 않습니다.

새 판은 성장·체력·적·방·층·시간을 초기화합니다. 새로고침도 판을 끝냅니다. 앱 설치와 오프라인 실행은 지원하지만 진행 중인 판의 영구 저장은 아직 없습니다.

## 크기와 난이도

`src/species.json`에 PokéAPI 원본 CSV의 키/몸무게와 PNG 불투명 영역을 저장합니다. 키는 decimeter 단위이며, 보이는 높이는 `32 × sqrt(키(m) / 0.4)` 게임 픽셀입니다. 1:1 비율 대신 완만한 제곱근 스케일을 써서 플레이 공간을 유지합니다. PNG의 투명 여백을 프레임에서 제외해 각 그림의 여백 차이가 크기 비교를 왜곡하지 않게 했습니다. 충돌 반경도 표시 높이와 연동됩니다.

|포켓몬|도감 키|표시 높이(약)|
|---|---:|---:|
|뮤|0.4m|32px|
|고오스|1.3m|58px|
|주뱃|0.8m|45px|
|또가스|0.6m|39px|
|질퍽이|0.9m|48px|
|델빌|0.6m|39px|
|어둠대신|0.6m|39px|
|팬텀|1.5m|62px|

층 상승 횟수를 L(0~4)이라 할 때 일반 적 체력은 `1 + 0.5L + 0.16L²`배, 속도는 `1 + 0.07L`배, 적 탄속은 `1 + 0.12L`배입니다. 팬텀 체력에는 `1 + 0.35L`가 추가 적용됩니다. B6 팬텀 HP는 180, B2는 약 2402입니다. 높은 층에서는 시설 기믹과 적 수가 추가되고 시설의 재작동 간격이 줄어듭니다. 실제 클리어 난이도는 지속 조정 대상입니다.

- 레이저: 1초 예고 → 0.9초 작동 → 휴지기. 가로 구간을 피해야 합니다.
- 독가스/적의 독 웅덩이: 접촉 후 2초간 중독 잔류. 처음에는 0.65초 반응 여유가 있습니다.
- 전기: 피해와 0.6초 이동 둔화.
- 고정 장비: 이동 및 양쪽 탄환을 차단. 부유 적은 넘어옵니다.
- 팬텀: 예고 후 반대편으로 순간이동하고 방사 탄막. HP 절반 아래에서는 12방향 탄막과 플레이어 위치의 예고 독 장판.

## 기술 합성

섀도볼, 스피드스타, 트라이어택, 불꽃세례, 얼다바람, 전기쇼크, 분열 강화, 환상빔, 고속이동, 독침, 용의파동, 기가드레인, 기충전, 반사 강화, 오물폭탄, 물대포, 냉동빔, 10만볼트, 화염방사.

각 기술은 `src/moves.ts`의 독립 modifier 데이터로 기본 공격에 가산됩니다. 색은 우선순위가 높은 기술, 동률이면 최근 기술을 사용하며 색 변화가 이전 효과를 지우지 않습니다. 현재 빔/화염 명칭의 기술은 빔 전용 렌더러 대신 기존 투사체에 사거리/관통/연사/상태 효과를 합성하는 데모 구현입니다.

효과 채널: 공격력, 간격, 탄속, 사거리, 크기, 개수, 관통, 유도, 분열, 화상, 둔화, 연쇄, 중독, 넉백, 치명타, 흡혈, 벽 반사, 폭발.

분열은 원탄 첫 적중에서만 발생하며 자탄은 재분열하지 않습니다. 자탄은 원탄 피해 55%, 사거리 360. 연쇄·폭발은 새로운 연쇄·폭발을 생성하지 않습니다. 동일 탄환이 같은 적에게 반복 피해를 주지 않습니다. 화상과 중독은 함께 적용하고, 재적중은 지속 시간을 갱신합니다.

상한: 동시 발사 5, 최소 간격 0.09초, 추가 관통 6, 유도 6, 둔화 65%, 연쇄 3, 반경 11, 탄속 960, 사거리 1200, 치명타 60%, 벽 반사 2, 폭발 범위 100. 총 탄환 상한 120을 플레이어 80/적 40으로 나누어, 플레이어 탄막이 적의 발사 자리를 소진하지 않게 합니다.

## 실행·배포

Node.js 22 이상.

```sh
npm install
npm run dev
npm test
npm run build
```

`main` push 시 GitHub Actions가 테스트/빌드 후 Pages로 배포합니다. `npm run build`는 전체 로컬 게임 리소스의 버전별 precache를 생성합니다. 새 서비스 워커는 기존 게임 창이 닫힌 뒤 활성화되어 진행 중인 판을 강제로 재시작하지 않습니다. 설치 화면에서 오프라인 준비 완료를 확인할 수 있습니다.

`?seed=3`처럼 10진수 32비트 시드를 지정하면 같은 던전/선택 경로를 재현합니다. 시드를 빼면 매번 새 판입니다. 층별 시드는 최초 시드에서 파생됩니다.

개발 서버의 `?qa=1`에는 브라우저 검증용 팬텀/복합 효과 버튼이 있습니다. 빌드 시 제거되며 배포판에서는 활성화되지 않습니다.

## 구조

- `dungeon.ts`, `run.ts`: 시드 던전, 방·보상·층 상태, 보스 진입과 상승 조건.
- `data.ts`, `species.json`, `scaling.ts`: 적 데이터, 도감 크기, 난이도 곡선, 시설 타이밍.
- `ai.ts`: 6종 일반 적과 팬텀 패턴.
- `lab.ts`: 방 장애물, 충돌/슬라이딩, 장식 배치.
- `moves.ts`, `combat.ts`: 기술 합성, 방향/피격 계산, 탄환 예산.
- `scene.ts`: Phaser 렌더링, 전투 및 UI 연결.
- `story.ts`, `shell.ts`, `shell.css`: 오프닝·메뉴·스토리·설치 안내.
- `audio.ts`: 합성 BGM/효과음.
- `scripts/build-sw.mjs`: 정적 리소스 캐시 생성.

리소스 출처/라이선스는 `public/assets/CREDITS.txt`와 `Kenney-LICENSE.txt`를 참고하세요. 플레이 중 외부 API 요청은 없습니다.
