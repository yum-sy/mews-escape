# Pokémon — Mew's Escape · Phase 2

뮤가 연구소의 연결된 방들을 탐험하고 기술 효과를 누적하는 웹 액션 로그라이크 프로토타입입니다.

[게임 실행](https://yum-sy.github.io/mews-escape/)

## 한 판의 흐름

1. 안전한 시작방에서 열린 문을 향해 이동합니다.
2. 랜덤하게 연결된 9개 방을 탐험합니다: 시작방 1개, 전투방 5개, 기술 보관실 2개, 출구 1개.
3. 전투방에서는 문이 잠깁니다. 모든 적을 처치하면 문이 열리고 세 가지 기술 중 하나를 선택합니다.
4. 기술 보관실에서도 한 번씩 보상을 선택합니다. 선택할 때 체력 1을 회복하고 기존 공격에 효과가 추가됩니다.
5. 모든 전투방을 클리어한 뒤 출구 방의 중앙 승강기로 이동하면 구역 탈출입니다.
6. 죽으면 현재 성장이 초기화됩니다. 새 던전 시작은 체력·탄환·처치 수·시간·방 상태·기술을 모두 새로 만듭니다.

클리어한 방과 수령한 보상은 해당 판 안에서 유지됩니다. 재방문으로 적이나 보상이 다시 생성되지 않습니다. 미니맵은 방문한 방과 현재 방에 연결된 미탐험 방을 표시합니다. S는 시작방, ✧는 기술 보관실, E는 출구입니다.

## 조작

- WASD: 이동. 대각선 속도 정규화.
- 방향키: 8방향 연속 염동력 공격. 인접 키 동시 입력으로 대각선 공격. 이동과 독립.
- 터치: 왼쪽 이동 스틱, 오른쪽 360° 조준 스틱. 중앙 8px 데드존에서는 발사 중지. pointerId별 캡처로 독립 입력.
- 열린 문의 중앙으로 계속 이동하면 방 전환. 닫힌 문으로는 이동할 수 없습니다.
- Esc 또는 상단 정지 버튼: 일시정지/재개. 보상 선택 중에는 이미 전투가 멈춥니다.
- 소리 버튼: 선택적 Web Audio 효과음. 기본 음소거.
- 창 비활성화 및 탭 숨김: 자동 일시정지.

## 기술과 합성 규칙

|기술/강화|누적 효과|최대 습득|
|---|---|---|
|섀도볼|공격력 +0.35, 추가 관통 +2|2|
|스피드스타|적 추적 회전 강도 +3.4|2|
|트라이어택|동시 발사 +2, 부채꼴 탄막|2|
|불꽃세례|2초간 초당 화상 피해 +1.2|2|
|얼다바람|2초간 이동 속도 감소 +35%|2|
|전기쇼크|175px 이내 추가 대상 +1에 공격력의 55% 연쇄 피해|3|
|분열 강화|원탄 첫 적중 시 작은 탄환 2개 생성|1|
|환상빔|공격력 +0.7, 탄환 반경 +2|3|
|고속이동|공격 간격 -0.035초|2|

- 기술 데이터의 독립 modifier를 기본 공격에 가산합니다. 조합별 특수 코드를 만들지 않습니다.
- 동시 발사 최대 5, 간격 최소 0.09초, 추가 관통 최대 6, 유도 강도 최대 6, 둔화 최대 65%, 연쇄 최대 3, 탄환 반경 최대 11.
- 유도·관통·다중 탄환·화상·둔화·연쇄는 함께 작동합니다. 동일 탄환은 같은 적을 두 번 맞히지 않습니다.
- 분열탄은 공격력 55%, 사거리 360이며 유도·관통·적중 상태 효과를 이어받습니다. 분열탄은 다시 분열하지 않고, 원탄도 최초 적중에서만 분열합니다.
- 화상과 둔화는 공존합니다. 연속 적중은 지속 시간을 갱신하며 동일 상태의 피해를 중복으로 무한 중첩하지 않습니다.
- 연쇄 피해는 다시 연쇄/분열을 발생시키지 않습니다.
- 색은 우선순위가 높은 기술을 사용하고, 같은 우선순위면 나중에 습득한 기술의 색을 사용합니다. 색 변화로 이전 효과가 제거되지는 않습니다.
- 플레이어/적 탄환을 합해 최대 120개. 만료/충돌/방 전환 시 객체를 정리합니다.

## 시드와 재현

기본 플레이는 시작할 때마다 새 32비트 랜덤 시드를 사용합니다. 오른쪽 미니맵 아래 시드를 16진수로 표시합니다.

재현 테스트는 URL에 10진수 시드를 넣습니다: `?seed=3`. 이 경우 새로 시작해도 같은 방 연결·적 배치·동일 선택 경로의 보상이 나옵니다. 일반 랜덤 플레이로 돌아가려면 쿼리를 제거합니다. 영구 저장은 아직 없으며 새로고침은 현재 판을 끝냅니다.

## 개발 및 배포

Node.js 22 이상 권장.

```sh
npm install
npm run dev
npm test
npm run build
```

`main` push 시 GitHub Actions가 테스트·빌드하고 GitHub Pages에 배포합니다. Vite 상대 base로 저장소 하위 URL에서도 리소스가 로드됩니다. `dist/`는 정적 결과물이며 HTTP 서버로 실행합니다.

## 구조

- `src/dungeon.ts`: 시드 난수, 연결 던전 생성, 방 유형/문 좌표 관계, 적 배치.
- `src/run.ts`: 한 판의 상태, 방 이동 조건, 클리어/보상/출구 상태.
- `src/moves.ts`: 기술 데이터, 독립 modifier, 합성 우선순위/상한, 중복 제한 보상 풀.
- `src/combat.ts`: 방향 벡터, 충돌, 피해/무적 계산.
- `src/input.ts`: 8방향 키보드 및 자유 각도 터치 입력.
- `src/scene.ts`: Phaser 전투/렌더링, 적 AI, 투사체와 적중 효과, 문/미니맵/HUD, 보상 UI 연결.
- `src/data.ts`: 기본 능력치와 적 데이터.
- `src/audio.ts`: 선택적 합성 효과음.

Phaser 3.90.0 + TypeScript + Vite. 단일 클라이언트 코드이며 플레이 중 외부 API 호출은 없습니다.
